# ZError 智慧树网站经验

此仓库提供 ZError Agent 在智慧树（zhihuishu.com）的通用操作经验与导航图谱。

在 ZError 打开「设置 → Agent → 网站 → 导入 GitHub 仓库」，粘贴 `https://github.com/Miaozeqiu/ZError-zhihuishu`，选择「智慧树」即可导入。

网站包位于 [skills/zhihuishu](skills/zhihuishu/)，包含操作经验、导航图谱、导入清单和网站图标。图标取自[智慧树官网](https://www.zhihuishu.com/)，用于标识对应服务。经验来源为 [ZError 内置站点资料](https://github.com/Miaozeqiu/ZError/tree/dev-improvements/src/services/agent/skills/bundled/site-learn/sites/zhihuishu.com)。
